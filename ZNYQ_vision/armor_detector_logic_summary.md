# `rm_auto_aim/armor_detector` 模块逻辑详解

本文档旨在详细解析 `armor_detector` 模块内部的图像处理流程、核心算法逻辑以及关键函数的实现。

## 一、 核心逻辑流程 (Top-Down)

`armor_detector` 的主入口是 `Detector::detect` 函数。其处理流程可以分解为以下几个关键步骤：

### 流程详解

1.  **图像预处理 (`preprocessImage`)**:
    *   接收原始的彩色RGB图像作为输入。
    *   **色彩空间转换**: 使用 `cv::cvtColor` 将图像从RGB转换为灰度图。
    *   **二值化**: 使用 `cv::threshold` 将灰度图转换为二值化图像。高于设定阈值 (`binary_thres`) 的像素点变为白色(255)，其余变为黑色(0)，从而突出显示灯条。

2.  **查找并筛选灯条 (`findLights`)**:
    *   **轮廓检测**: 在二值化图像上使用 `cv::findContours` 寻找所有独立的白色区域的轮廓。
    *   **轮廓迭代与筛选**: 遍历每一个找到的轮廓，并通过一系列条件进行筛选，以确定其是否为一个有效的灯条。
        *   **拟合外接矩形**: 使用 `cv::minAreaRect` 拟合轮廓的最小旋转外接矩形，获得灯条的中心点、长、宽和倾斜角度等基本信息。
        *   **最小二乘法拟合直线**: 使用 `cv::fitLine` 对轮廓点进行直线拟合，更精确地计算灯条的倾斜角度和端点（`top`, `bottom`）。
        *   **几何条件筛选 (`isLight`)**:
            *   **长宽比**: 检查旋转外接矩形的长宽比是否在预设的合理范围内 (`l.min_ratio`, `l.max_ratio`)。
            *   **倾斜角度**: 检查灯条的倾斜角度是否小于最大允许角度 (`l.max_angle`)。
    *   **颜色判断**: 对于通过几何筛选的灯条，提取其在原始RGB图像中的ROI（感兴趣区域），并计算区域内红色和蓝色通道的像素值总和，以判断灯条颜色（`RED` 或 `BLUE`）。

3.  **灯条匹配与装甲板组合 (`matchLights`)**:
    *   **双重循环匹配**: 采用双重循环遍历所有已识别的灯条，尝试将它们两两配对。
    *   **颜色一致性检查**: 确保两个灯条的颜色都与目标检测颜色 (`detect_color`) 相匹配。
    *   **几何约束判断 (`isArmor`)**: 对每一对灯条，计算它们之间的几何关系是否满足构成装甲板的条件。
        *   **灯条长度比**: 两灯条的长度比例 (`light_length_ratio`) 是否在允许范围内。
        *   **中心点距离**: 两灯条中心点的距离与灯条平均长度的比值 (`center_distance`) 是否在合理范围内（区分大、小装甲板）。
        *   **中心连线角度**: 两灯条中心点连线与水平线的夹角 (`angle`) 是否足够小。
    *   **有效组合**: 如果一对灯条通过了所有几何约束，就将它们组合成一个 `Armor` 对象，并根据中心点距离判断其为 `LARGE` 或 `SMALL` 类型。

4.  **数字识别 (`NumberClassifier`)**:
    *   **图像提取 (`extractNumbers`)**:
        *   对于每一个识别出的 `Armor` 对象，确定其四个顶点（两个灯条的四个端点）。
        *   使用 `cv::getPerspectiveTransform` 和 `cv::warpPerspective` 进行透视变换，将倾斜的装甲板区域校正为一个矩形的、正面的“数字图像”。
        *   对校正后的图像进行裁剪、灰度化和二值化处理，得到一个标准化的数字图像（`armor.number_img`）。
    *   **模型推理 (`classify`)**:
        *   将标准化的数字图像输入到一个预先加载的 **ONNX神经网络模型** (`net_`) 中。
        *   通过 `net_.forward()` 进行前向传播，得到每个类别的置信度。
        *   对输出结果进行Softmax处理，找到置信度最高的类别作为识别结果。
        *   **结果筛选**: 剔除置信度低于阈值 (`threshold`) 或识别出的数字与装甲板类型（大/小）不匹配的装甲板。

5.  **PnP三维位姿解算 (`PnpSolver`)**:
    *   在 `detector_node.cpp` 中（未在 `detector.cpp` 体现），对于最终筛选出的装甲板，会调用 `PnpSolver::solvePnP`。
    *   **构建2D-3D点对**:
        *   **2D图像点**: 装甲板的四个顶点在图像中的像素坐标。
        *   **3D世界点**: 预先定义好的装甲板3D模型坐标（区分大小装甲板，单位为米）。
    *   **调用OpenCV求解器**: 使用 `cv::solvePnP` 函数，传入2D-3D点对、相机内参矩阵 (`camera_matrix_`) 和畸变系数 (`dist_coeffs_`)。
    *   **输出**: 函数最终计算出装甲板相对于相机的旋转向量 (`rvec`) 和平移向量 (`tvec`)，即三维位姿信息。

## 二、 关键函数与类分析

-   `cv::cvtColor`: 用于色彩空间转换，是图像预处理的第一步。
-   `cv::threshold`: 实现图像二值化，是分离灯条与背景的关键。
-   `cv::findContours`: 用于寻找二值图像中的所有轮廓，是识别所有可能灯条的基础。
-   `cv::minAreaRect`: 计算包裹轮廓的最小旋转矩形，用于快速获取灯条的基本几何属性。
-   `cv::fitLine`: 通过最小二乘法拟合直线，比`minAreaRect`更精确地确定灯条的姿态和端点。
-   `cv::getPerspectiveTransform` / `cv::warpPerspective`: 用于执行透视变换，是数字识别前校正图像的关键步骤。
-   `cv::dnn::readNetFromONNX`: OpenCV的DNN模块函数，用于加载ONNX格式的深度学习模型。
-   `cv::solvePnP`: OpenCV的核心函数之一，用于根据物体的2D图像点和3D模型点来求解其在相机坐标系下的位姿。
-   **`Detector` 类**: 封装了整个识别算法的主要流程。
-   **`NumberClassifier` 类**: 封装了数字提取和ONNX模型推理的全部逻辑。
-   **`PnpSolver` 类**: 封装了PnP位姿解算所需的相机参数和3D模型点，并提供了简洁的调用接口。
