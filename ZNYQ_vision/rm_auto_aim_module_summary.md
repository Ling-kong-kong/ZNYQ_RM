# rm_auto_aim 模块功能汇整

本文档详细说明了 `rm_auto_aim` ROS 2软件包中各个核心模块的功能。

## 1. armor_detector (装甲板检测模块)

- **功能**: 此模块负责订阅来自相机的图像数据流和相机参数。
- **核心任务**:
    - 对实时图像进行处理，以识别敌方机器人的装甲板。
    - 在识别到装甲板后，利用相机参数（如内参、畸变系数）和PnP算法来解算其在三维空间中的位置。
- **输出**:
    - 发布已识别装甲板的三维坐标。该坐标通常是相对于相机坐标系的，即以相机光心为原点。

## 2. armor_tracker (装甲板跟踪模块)

- **功能**: 此模块订阅 `armor_detector` 发布的装甲板位置信息，并对其进行跟踪。
- **核心任务**:
    - 接收装甲板在相机坐标系下的位置数据。
    - 结合机器人自身的坐标转换信息（TF变换），将装甲板位置转换到一个固定的惯性坐标系下（通常是以云台中心为原点，IMU初始化的Yaw朝向为X轴）。
    - 使用扩展卡尔曼滤波器（EKF）对目标进行状态估计和运动预测，实现稳定跟踪。
- **输出**:
    - 发布被跟踪目标在指定惯性坐标系下的状态信息（如位置、速度）。

## 3. auto_aim_interfaces (自瞄接口模块)

- **功能**: 定义了 `rm_auto_aim` 系统中各个节点之间通信所用的数据结构。
- **核心任务**:
    - 提供自定义的ROS 2消息（`.msg`）和服务（`.srv`）类型。
    - 确保数据在 `armor_detector`、`armor_tracker` 及其他节点之间能够标准化地传输。
- **内容**:
    - 包含如 `Armor.msg`, `Armors.msg`, `Target.msg` 等用于描述装甲板和目标信息的接口。
    - 包含用于调试（Debug）的自定义消息类型。

## 4. projectile_motion (弹道解算模块)

- **功能**: 此模块不作为独立的ROS节点运行，而是作为一个库被其他节点调用，用于弹道建模和解算。
- **核心任务**:
    - 根据目标点的三维空间位置，计算出云台需要旋转的Pitch（俯仰）和Yaw（偏航）角度，以确保弹丸能够命中目标。
    - 提供了多种弹道模型求解器：
        - **`GravityProjectileSolver`**: 只考虑重力影响的抛物线弹道模型。
        - **`GafProjectileSolver`**: 同时考虑重力和空气阻力的弹道模型（近似模型，可能不稳定）。
- **使用方式**:
    - 通过创建一个 `GimbalTransformTool` 工具实例，并为其配置一个弹道求解器，即可调用其 `solve` 方法来计算所需的云台角度。
